# Design system

## Direction

The experience should be energetic, premium, fast, and suitable for teenagers without resembling a corporate dashboard or copying another learning product. Screens should have one primary action and large touch targets.

## Foundation contract

Application-owned tokens cover semantic colors, spacing, typography, radii, borders, elevation, and motion. UI primitives consume semantic tokens rather than raw values. A large UI framework is intentionally absent.

Accessibility requirements include semantic labels, dynamic-text tolerance, sufficient contrast, reduced-motion support, and feedback that does not rely only on red or green. Interactive controls target at least 44 points.

Milestone 1 proves only token wiring and one reusable button. Visual brand, typography licensing, dark-theme release scope, and motion language remain open design decisions.
